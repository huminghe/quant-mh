# A股量化调研结论汇总

## 策略组合方向

确定组合：ETF 趋势轮动（30%）+ 指数增强（30%）+ 商品期货 CTA（30%）+ 可转债（10%）

开发顺序：ETF 轮动（验证框架）→ 指数增强 → 商品期货 CTA。

CTA 与股票 Alpha 相关性低，熊市时天然对冲（2022 年股市大跌，商品 CTA 普遍正收益）。

## 交易接口

- 股票/ETF/可转债：MiniQMT（国金证券，门槛 10 万）
- 期货：CTP + vnpy（期货公司开户，申请 API 权限，Linux 云服务器部署）

## 回测工具

- vectorbt：主力（多因子/ETF 轮动），向量化快速
- Qlib：因子积累后迁移，内置 Alpha158/Point-in-Time/IC 检验
- vnpy：期货 CTA 回测 + 实盘一体化

## 有效/失效因子

- **有效**：短期反转（最强，ICIR -0.244，负向使用）、质量（ROE/现金流）、低波动、盈利质量、残差动量
- **失效**：小市值（2024年2月踩踏证伪）、简单低估值、价格动量（A股整体反转市场）

## 指数增强策略

- 选股池：沪深300/中证500，月度调仓
- 财务数据季度披露，需 point-in-time 处理，安全缓冲 45-60 天

## 组合逻辑

质量因子做**负向过滤**，低波动因子做**正向选股**：
```
沪深300/中证500 → 质量过滤（现金流质量>0.7，ROE稳定性前50%）
→ 在通过质量过滤的股票里选特质波动率最低的30只
→ 行业中性化（每个行业不超过总仓位20%）→ 月度调仓
```

## 机构方法论认知

- 深度学习不替代因子挖掘，替代"人工设定因子权重"。VSN+LSTM（VLSTM）在2025年Oxford期货基准测试Sharpe 2.40第一
- 纯Transformer架构系统性失败（无显式噪声过滤）；原始OHLCV特征优于技术指标衍生特征（仅在深度学习模型上成立）
- 当前阶段（数据量不足）不值得投入深度学习，LightGBM + 精选因子（10-20个）性价比最高
- GMM市场状态识别：把收益率建模为几个高斯分布的混合，识别当前状态，不同状态用不同因子权重（Two Sigma做法）

## Alpha衰减

- 动量、短期反转：半衰期6-24个月，衰减快
- 低波动、价值、质量：衰减慢，结构性风险溢价
- 2015年后衰减加速，与因子ETF规模增长高度相关

## 其他策略思想（加密货币适用性）

- **截面动量**：加密货币中等，不稳定，2022-2023年完全失效
- **资金费率套利**：加密货币最强（机构规模>40亿美元），牛市年化15-30%，用户暂时不做
- **统计套利**：BTC-ETH配对最稳定，但协整关系会断裂，个人可行性中低
- **均值回归（加密货币）**：个人可复制形式收益不确定性高；单资产日线RSI均值回归明确无效（8年CAGR -5.3%）
- **事件驱动**：代币解锁/交易所上市有实证，只能作为辅助信号

截面均值回归在TradingView无法实现（单标的架构），需要Python实现。A股指数增强开发时，任何因子都要先做截面排名。
