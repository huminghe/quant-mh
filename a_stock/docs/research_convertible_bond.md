# 可转债双低策略调研结论

## 当前状态（2026-09-16）

**结论：证伪，不接入实盘。** 双低因子（`双低值 = 转债价格 + 100 × 转股溢价率(%)`）Rank IC在2022年可转债交易新规前后均未达到项目阈值（|IC均值|≥0.03），信用过滤（正股ST状态+资产负债率）对违约踩雷率几乎无改善，样本外夏普/样本内夏普比值0.44-0.46触及trading-standards.md"可能过拟合"警戒线（<0.5）。三轮追加稳健性检验（滚动窗口、超额收益拆分、分段点敏感性扫描）均未推翻此判断，反而进一步加固：改用超额收益（剔除可转债市场beta后单独看选股能力）后，年化收益均值从18%+骤降到7%左右，且负夏普窗口占比不降反升到27.5%-32.5%（信用过滤版已超30%不稳健阈值）；逐季度扫描23个候选样本内外分段点，唯一双侧样本量可信的中段区间（2020-2022年）夏普比普遍比原判断更差。Top20%分组的原始超额收益（gross，未扣成本）在两段历史区间都为正，但五项证据链一致指向证伪，不足以支撑接入实盘的结论。完整证据见下方五项证据链（Phase 1-5）。

## 滚动窗口稳健性检验（Phase 4，2026-09-16追加）

用户质疑"样本内外单一分段点（2022-01-01）的对比是否只是运气好/差撞上特定切点"，追加滚动24个月窗口（逐月滑动，覆盖全样本2018-2026）检验结论对切点选择的敏感度，方法同ETF轮动`etf_rotation_v38_fundamental_signal_ablation.py`的滚动2年检验思路。

| | 无过滤 | 信用过滤 |
|---|---|---|
| 窗口数 | 80 | 80 |
| 年化收益 均值±std | +18.46%±16.40% | +18.37%±16.92% |
| 年化夏普 均值±std | +1.03±0.99 | +0.97±0.96 |
| 年化夏普 最小/最大 | -0.91 / +2.85 | -0.94 / +2.62 |
| 最大回撤 均值±std | -12.48%±5.85% | -13.02%±6.45% |
| 窗口夏普<0占比 | 18.8% | 22.5% |

**结论：波动幅度过大，进一步支持证伪判断，不是反证。** 夏普标准差(0.99)与均值(1.03)几乎同量级，说明策略表现高度依赖测试窗口的选取——最差窗口夏普为负（-0.91~-0.94，真实亏损而非仅收益变差），18.8%-22.5%的窗口直接跌入负夏普。这与Phase 3单一分段点发现的"样本内外夏普腰斩"是同一现象的另一种呈现：不依赖2022年新规这一个特定切点，任意滑动窗口下结论都不稳定。信用过滤版本未改善这一波动性，窗口夏普<0占比反而略高于无过滤版本(22.5% vs 18.8%)，与Phase 2/3"信用过滤对风险无改善"的结论一致。

## 改用超额收益重新检验滚动窗口（Phase 4b，2026-09-16追加）

以上Phase 4统计的都是`strategy`列（策略扣成本后的**绝对收益**），会混入可转债市场整体的beta周期性（新规前转债市场普遍走牛，2022-2024违约潮+走弱，2025年起回暖）。为了单独衡量双低因子的**选股能力（alpha）**本身是否稳健，改用`strategy - benchmark`（策略净收益减去当月全部可用转债池等权平均收益）重跑同一套滚动24个月窗口检验：

| | 无过滤（绝对收益） | 无过滤（超额收益） | 信用过滤（绝对收益） | 信用过滤（超额收益） |
|---|---|---|---|---|
| 年化收益 均值±std | +18.46%±16.40% | +7.68%±7.35% | +18.37%±16.92% | +7.10%±6.82% |
| 年化夏普 均值±std | +1.03±0.99 | +0.75±0.92 | +0.97±0.96 | +0.65±0.86 |
| 年化夏普 最小/最大 | -0.91 / +2.85 | -0.82 / +2.35 | -0.94 / +2.62 | -0.94 / +2.26 |
| 最大回撤 均值±std | -12.48%±5.85% | -4.44%±2.22% | -13.02%±6.45% | -4.69%±2.33% |
| 窗口夏普<0占比 | 18.8% | **27.5%** | 22.5% | **32.5%** |

**两个发现，都指向同一个结论：**

1. **绝对收益里大部分是beta，不是alpha。** 年化收益均值从+18.46%骤降到+7.68%（降幅近六成），说明用户观察到的"看起来还不错的收益"，很大一部分是转债市场本身这几年涨得好，不是双低因子选股选得好。
2. **剔除beta之后，alpha本身反而更不稳定，不是更稳。** 窗口夏普<0占比不降反升（无过滤18.8%→27.5%，信用过滤22.5%→32.5%），信用过滤版本的超额收益夏普<0占比(32.5%)已经超过trading-standards.md的30%"不稳健"阈值，无过滤版本(27.5%)落在20-25%~30%的灰色区间上沿。这说明此前观察到的"策略表现有周期性"，很大程度上是转债市场beta本身的周期，一旦剔除beta，纯选股能力的窗口间波动反而暴露得更明显——不是"因为混入了beta才显得不稳定"，而是"剔除beta后才看清楚真的不稳定"。

回测代码：`a_stock/backtest/cb_lowprice_backtest.py`（Phase 4用`rolling_window_stats`，Phase 4b用`rolling_window_excess_stats`，两者共用`_rolling_stats_from_series`，`ROLLING_WINDOW_MONTHS=24`）。

**解读：夏普比不是随机波动，是分三段的单调曲线，其中只有中段有效。**

1. **早期切点（2019-07~2020-01）**：样本内仅18-24个月，估计噪音过大，参考价值有限。
2. **中段切点（2020-04~2022-10，约2年，9个候选）**：唯一双侧样本量都充足的区间（IS 27-57月，OOS 46-76月）。夏普比全部落在0.40-0.85，多个切点（2020-07/0.537、2021-01/0.547、2021-07/0.404、2021-10/0.392）比原始2022-01-01切点（0.440）更差。**说明Phase 3发现的"样本外夏普腰斩"不是2022-01-01这一个特定点位的偶然产物，在整整两年的候选切点范围内普遍存在，多数情况下比原判断更严重。**
3. **晚期切点（2023-01之后）**：夏普比翻转上升并持续走高，但这是统计假象而非策略转稳——样本外窗口从43个月一路收缩到19个月，且收缩后的窗口越来越集中在2025-2026回暖尾段，均值被少数几个高夏普月份主导，不是独立样本外考验，而是Phase 4末端"不要把样本末端高数字当作策略又行了"这一警告的另一种呈现。

**结论：本次检验没有推翻"可能过拟合"判断，反而加固了它。** 唯一双侧样本量可信的中段区间（9个候选切点）里，夏普比普遍比原始切点更差；晚期切点看起来"稳"纯属窗口收缩的统计假象。

## 结论

五项证据链一致指向"不接入实盘"：
1. Rank IC初筛未过筛（新规前后均<0.03阈值）
2. 信用过滤对违约密集期踩雷率零改善，说明ST/资产负债率这两个信号对可转债违约风险的边际解释力不足（转债违约往往是突发流动性危机，财务比率的季度频率滞后性太强，PIT安全但预警力不足）
3. 样本外/样本内夏普比0.44-0.46，触发过拟合警戒线，新规后收益和风险特征均明显弱化
4. 滚动24个月窗口稳健性检验（Phase 4/4b）证明结论不依赖单一分段点选择：绝对收益版窗口夏普波动幅度（std=0.96-0.99）接近均值本身，18.8%-22.5%窗口为负夏普；改用超额收益（剔除转债市场beta后单独看选股能力）重跑后，年化收益均值从18%+骤降到7%左右（说明此前多数收益来自市场beta而非选股alpha），且负夏普窗口占比不降反升到27.5%-32.5%（信用过滤版本已超过30%不稳健阈值），证明双低因子的纯选股能力比表面数字显示的更不稳定
5. 分段点敏感性检验（Phase 5）逐季度扫描23个候选分段点，证明"样本外夏普腰斩"不是2022-01-01这一个特定切点撞上的运气——唯一双侧样本量可信的中段区间（2020-2022年，9个候选切点）里，夏普比普遍比原始切点（0.440）更差（多个低至0.39-0.40）；2023年后切点看起来"过拟合警报解除"是样本外窗口收缩到19-43个月、被2025-2026回暖尾段主导的统计假象，不是策略真的转稳

Top20%分组gross超额为正这一点不足以推翻上述结论，只说明双低值作为"低估值+低风险"的直觉代理指标仍有一定描述性价值，但不构成可交易的稳健alpha信号。

**不排除的方向**：若未来有更高频/更及时的违约预警信号（如成交量异动、评级下调公告的PIT安全处理方式），或者双低策略作为分散仓位工具（而非alpha来源）用于降低组合整体波动，可能仍有讨论空间，但当前证据不支持作为独立策略线投入10%仓位。
