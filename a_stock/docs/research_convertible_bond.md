# 可转债双低策略调研结论

## 当前状态（2026-09-18）

**结论：证伪，不接入实盘。** 双低因子（`双低值 = 转债价格 + 100 × 转股溢价率(%)`）Rank IC在2022年可转债交易新规前后均未达到项目阈值（|IC均值|≥0.03），信用过滤（正股ST状态+资产负债率）对违约踩雷率几乎无改善，样本外夏普/样本内夏普比值0.44-0.46触及trading-standards.md"可能过拟合"警戒线（<0.5）。三轮追加稳健性检验（滚动窗口、超额收益拆分、分段点敏感性扫描）均未推翻此判断，反而进一步加固：改用超额收益（剔除可转债市场beta后单独看选股能力）后，年化收益均值从18%+骤降到7%左右，且负夏普窗口占比不降反升到27.5%-32.5%（信用过滤版已超30%不稳健阈值）；逐季度扫描23个候选样本内外分段点，唯一双侧样本量可信的中段区间（2020-2022年）夏普比普遍比原判断更差。Top20%分组的原始超额收益（gross，未扣成本）在两段历史区间都为正，但五项证据链一致指向证伪，不足以支撑接入实盘的结论。完整证据见下方五项证据链（Phase 1-5）。

**追加方向（Phase 6/7，2026-09-18）**：此前留的两个"不排除的方向"——更高频违约预警信号、双低值作为组合分散工具——均已测试并证伪。price/SV信号在已知违约案例上滞后于ST确认（非预警指标）；加入ETF轮动组合的全样本权重扫描看似正向，但滚动24个月窗口检验显示跑输纯ETF轮动的窗口占比32.5%-46.2%，全部超过不稳健阈值，是统计假象。详见下方对应小节。

## 滚动窗口稳健性检验（Phase 4，2026-09-16追加）

用户质疑"样本内外单一分段点（2022-01-01）的对比是否只是运气好/差撞上特定切点"，追加滚动24个月窗口（逐月滑动，覆盖全样本2018-2026）检验结论对切点选择的敏感度，方法同ETF轮动`etf_rotation_v38_fundamental_signal_ablation.py`的滚动2年检验思路。

| | 无过滤 | 信用过滤 |
|---|---|---|
| 窗口数 | 80 | 80 |
| 年化收益 均值±std | +18.46%±16.40% | +18.37%±16.92% |
| 年化夏普 均值±std | +1.03±0.99 | +0.97±0.96 |
| 年化夏普 最小/最大 | -0.91 / +2.85 | -0.94 / +2.62 |

| 窗口夏普<0占比 | 18.8% | 22.5% |

**结论：波动幅度过大，进一步支持证伪判断，不是反证。** 夏普标准差(0.99)与均值(1.03)几乎同量级，说明策略表现高度依赖测试窗口的选取——最差窗口夏普为负（-0.91~-0.94，真实亏损而非仅收益变差），18.8%-22.5%的窗口直接跌入负夏普。这与Phase 3单一分段点发现的"样本内外夏普腰斩"是同一现象的另一种呈现：不依赖2022年新规这一个特定切点，任意滑动窗口下结论都不稳定。信用过滤版本未改善这一波动性，窗口夏普<0占比反而略高于无过滤版本(22.5% vs 18.8%)，与Phase 2/3"信用过滤对风险无改善"的结论一致。

## 改用超额收益重新检验滚动窗口（Phase 4b，2026-09-16追加）

以上Phase 4统计的都是`strategy`列（策略扣成本后的**绝对收益**），会混入可转债市场整体的beta周期性（新规前转债市场普遍走牛，2022-2024违约潮+走弱，2025年起回暖）。为了单独衡量双低因子的**选股能力（alpha）**本身是否稳健，改用`strategy - benchmark`（策略净收益减去当月全部可用转债池等权平均收益）重跑同一套滚动24个月窗口检验：

| | 无过滤（绝对收益） | 无过滤（超额收益） | 信用过滤（绝对收益） | 信用过滤（超额收益） |
|---|---|---|---|---|
| 年化收益 均值±std | +18.46%±16.40% | +7.68%±7.35% | +18.37%±16.92% | +7.10%±6.82% |
| 年化夏普 均值±std | +1.03±0.99 | +0.75±0.92 | +0.97±0.96 | +0.65±0.86 |
| 年化夏普 最小/最大 | -0.91 / +2.85 | -0.82 / +2.35 | -0.94 / +2.62 | -0.94 / +2.26 |
| 最大回撤 均值±std | -12.48%±5.85% | -4.44%±2.22% | -13.02%±6.45% | -4.69%±2.33% |
| 窗口夏普<0占比 | 18.8% | **27.5%** | 22.5% | **32.5%** |

**两个发现，都指向同一个结论：**

1. **绝对收益里大部分是beta，不是alpha。** 年化收益均值从+18.46%骤降到+7.68%（降幅近六成），说明用户观察到的"看起来还不错的收益"，很大一部分是转债市场本身这几年涨得好，不是双低因子选股选得好。
2. **剔除beta之后，alpha本身反而更不稳定，不是更稳。** 窗口夏普<0占比不降反升（无过滤18.8%→27.5%，信用过滤22.5%→32.5%），信用过滤版本的超额收益夏普<0占比(32.5%)已经超过trading-standards.md的30%"不稳健"阈值，无过滤版本(27.5%)落在20-25%~30%的灰色区间上沿。这说明此前观察到的"策略表现有周期性"，很大程度上是转债市场beta本身的周期，一旦剔除beta，纯选股能力的窗口间波动反而暴露得更明显——不是"因为混入了beta才显得不稳定"，而是"剔除beta后才看清楚真的不稳定"。

回测代码：`a_stock/backtest/cb_lowprice_backtest.py`（Phase 4用`rolling_window_stats`，Phase 4b用`rolling_window_excess_stats`，两者共用`_rolling_stats_from_series`，`ROLLING_WINDOW_MONTHS=24`）。

## 结论

五项证据链一致指向"不接入实盘"：
1. Rank IC初筛未过筛（新规前后均<0.03阈值）
2. 信用过滤对违约密集期踩雷率零改善，说明ST/资产负债率这两个信号对可转债违约风险的边际解释力不足（转债违约往往是突发流动性危机，财务比率的季度频率滞后性太强，PIT安全但预警力不足）
3. 样本外/样本内夏普比0.44-0.46，触发过拟合警戒线，新规后收益和风险特征均明显弱化
4. 滚动24个月窗口稳健性检验（Phase 4/4b）证明结论不依赖单一分段点选择：绝对收益版窗口夏普波动幅度（std=0.96-0.99）接近均值本身，18.8%-22.5%窗口为负夏普；改用超额收益（剔除转债市场beta后单独看选股能力）重跑后，年化收益均值从18%+骤降到7%左右（说明此前多数收益来自市场beta而非选股alpha），且负夏普窗口占比不降反升到27.5%-32.5%（信用过滤版本已超过30%不稳健阈值），证明双低因子的纯选股能力比表面数字显示的更不稳定
5. 分段点敏感性检验（Phase 5）逐季度扫描23个候选分段点，证明"样本外夏普腰斩"不是2022-01-01这一个特定切点撞上的运气——唯一双侧样本量可信的中段区间（2020-2022年，9个候选切点）里，夏普比普遍比原始切点（0.440）更差（多个低至0.39-0.40）；2023年后切点看起来"过拟合警报解除"是样本外窗口收缩到19-43个月、被2025-2026回暖尾段主导的统计假象，不是策略真的转稳

Top20%分组gross超额为正这一点不足以推翻上述结论，只说明双低值作为"低估值+低风险"的直觉代理指标仍有一定描述性价值，但不构成可交易的稳健alpha信号。

**曾经不排除的方向（均已于2026-09-18测试完毕并证伪，见Phase 6/Phase 7）**：更高频违约预警信号（Phase 6：price/SV信号滞后于ST确认，无预警价值；评级接口权限不可用）、双低策略作为分散仓位工具（Phase 7：全样本权重扫描看似正向，滚动窗口检验后跑输占比32.5%-46.2%全部超过不稳健阈值，是统计假象）。两个方向均未推翻"不接入实盘"的整体结论，可转债双低策略调研到此完整闭环。

## 追加调研：高频违约预警信号可行性（Phase 6，2026-09-18）

**结论：证伪，price/SV信号不具备预警价值，方向不可行。**

针对上述"不排除的方向"第一条，测试了两个候选高频信号的数据可行性：

1. **评级下调**：tushare `cb_rate` 接口权限不足，调用返回的DataFrame只有`ts_code`列，评级字段被过滤——当前账号无法获取历史评级数据，与akshare"仅返回当前快照评级"的已知限制一致（PIT前视偏差问题依旧无法绕过）。**此路径不可行，无需继续测试。**

2. **price/SV（转债收盘价/纯债价值）**：用`cb_premium_history.parquet`全市场计算，触发规则为"连续20日窗口内≥75%交易日price/SV<0.9"。

   - 全市场历史上共**82只**转债触发过该信号
   - 用Phase 0记录的6只已知违约标的核对：82只里仅6只是已知违约（精确率7.3%，假阳性率92.7%）
   - 扩大ground truth口径为"正股历史上是否曾被实施ST"（更宽松，覆盖信用风险的前置信号，非仅限违约）：82只里22只命中（27%），60只（73%）正股从未ST
   - **关键检验——时序先后**：对22只ST命中标的逐一核对"price/SV信号首次触发日"与"正股首次ST日"的先后顺序。结果：**6只已知违约标的中，无一例外全部是信号触发晚于或与ST同期**（提前量-8天到-8508天，即信号在ST之后才触发，最短的-8天/-10天/-36天分别对应搜特转债/全筑转债/正邦转债，仍是滞后而非领先）。唯一出现"信号领先于ST"的6个案例（提前量+69天到+682天），无一是已知违约标的，均为触发信号但正常存续/退出的转债（如龙大转债、三房转债、普利转退）。

   **判断**：price/SV在已知违约案例上是滞后指标，不是预警指标——转债价格跌破纯债价值往往和ST公告同步或更晚才形成"连续75%交易日"的确认窗口，无法提供有效提前量。信号在正常存续标的上大量触发（73%假阳性，且其中相当部分后续走势正常），进一步说明该信号对预警任务的判别力不足。

3. **数据伪影修正记录**：核实疑似违约名单时发现`cb_daily_all.parquet`停牌期间`close`被填充为0.000，用`close<60`筛选会将强赎/转股类正常退出误判为价格暴跌违约（如128023.SZ、128025.SZ）。修复方法：用`vol>0`过滤取最后有效交易价格。修正后确认128119.SZ龙大转债（最后有效价73.999）、123099.SZ普利转退（最后有效价79.001）是新发现的低价退出标的，但核查发现两者均为正常到期/公告退市（龙大转债是"公告到期赎回"，call_price=115；普利转退是*ST后正常退市整理期退出），不是信用违约，不应计入违约样本。

**方向A（高频违约预警信号）到此判定为方向性证伪，不再继续Phase 2/IC检验。** 现有数据条件下（评级不可得、价格类信号滞后）没有找到具备真实预警价值的候选信号。

## 追加调研：双低值作为组合分散工具（Phase 7，2026-09-18）

**结论：证伪，全样本正向结论是滚动窗口层面的假象，不作为分散工具接入。**

针对"不排除的方向"第二条，测试双低策略不追求自身alpha、只作为低相关分散仓位加入现有ETF轮动组合（431池+flow单独配置，当前线上正式配置）后能否改善组合风险调整收益。

回测代码：`a_stock/backtest/etf_cb_diversification_test.py`。方法：复现ETF轮动431池+flow月度收益序列（103个月，2018-02~2026-08），与`cb_lowprice_backtest.py`无过滤版月度收益对齐后按0%-100%权重扫描，同时看绝对收益（含转债市场beta）和超额收益（`strategy-benchmark`，剔除beta，Phase 4b口径）两个版本。

**对齐方式说明**：`cb_lowprice_backtest.py`的`date`列语义是持有期起点（建仓月末），ETF轮动月度收益索引是持有期终点（标准`pct_change()`语义），直接按date合并会错位一个月。修正为`(date.to_period("M") + 1).to_timestamp("M")`后，共同月份数103（与两个原始序列长度完全匹配）。

**全样本权重扫描（103个月，看起来是正向结果）**：

| 双低权重 | 夏普(绝对收益) | 夏普(超额收益) |
|---|---|---|
| 0%（纯ETF轮动） | 0.644 | 0.644 |
| 10% | 0.713 | 0.674 |
| 30% | 0.868 | 0.752 |
| 50% | 1.020 | 0.864 |
| 80%（两个版本峰值） | 1.124 | 1.055 |
| 100% | 1.076 | 0.958 |

月度收益相关系数：绝对收益0.309，超额收益0.204（低相关，理论上具备分散潜力）。两个版本都在80%权重出现内部峰值后回落（不是单调走向100%边界），形态上符合马科维茨分散效应而非"双低本身收益好所以越多越好"的假象。

**滚动24个月窗口稳健性检验（逐月滑动，n=80个窗口，关键检验）**：

| 双低权重 | 跑输纯ETF窗口占比(绝对收益) | 跑输纯ETF窗口占比(超额收益) |
|---|---|---|
| 10% | 32.5% | 40.0% |
| 30% | 35.0% | 41.2% |
| 50% | 38.8% | 42.5% |
| 80% | 41.2% | 46.2% |

**结论：全样本正向结论是假象，滚动窗口检验后证伪。** 所有测试权重在80个滚动窗口里跑输纯ETF轮动的占比全部超过trading-standards.md的30%不稳健阈值（32.5%-46.2%），且随双低权重上升该占比不降反升——说明全样本汇总看到的"加双低仓位夏普更高"，是被少数窗口的大幅正向表现主导的统计假象，不是在大多数历史时期都能稳定复现的分散效应。这与Phase 4/4b/5对双低因子本身的证伪模式一致：单点/全样本对比看起来不错，拆开成滚动窗口后暴露出高失败率。

**判断：双低值作为组合分散工具的方向同样判定证伪，不接入实盘。** 至此，"不排除的方向"提出的两个候选（高频预警信号、分散工具用法）均已测试完毕，均未推翻可转债双低策略"不接入实盘"的整体结论。
