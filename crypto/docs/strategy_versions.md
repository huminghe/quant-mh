## 当前实际部署

**所有标的统一配置：v2 + v3_205m，各 50% 仓位**

| 标的 | 策略 | 仓位 |
|------|------|------|
| BTC  | v2 + v3_205m | 各 50% |
| ETH  | v2 + v3_205m | 各 50% |
| SOL  | v2 + v3_205m | 各 50% |
| DOGE | v2 + v3_205m | 各 50% |

**为什么从 V1（EMA）切换到 v2+v3_205m：**

2026-05-18 回测（2019-2026，每标的 10,000 USDT）显示，等权多策略组合全面优于纯 V1：

| 指标 | 纯 V1（BTC+ETH+SOL） | 等权组合（含 DOGE） |
|------|--------------------|--------------------|
| CAGR | 21.3% | 29.4% |
| 月度 Sharpe | 1.68 | 2.46 |
| 最大月回撤 | -8,714 USDT | -8,244 USDT |
| 月胜率 | 71% | 76% |

V1（EMA）在 2025-2026 年明显落后（SOL_ema 近 6 月 -5,246 USDT），V2/V3 同期均在峰值附近。

**部署注意事项：**
- 各策略用独立 OKX Signal Bot，已实测互不影响（EXIT 信号不会平掉另一个 Bot 的仓位，2026-06-03 验证）
- 合并信号每年只节省 774 USDT，不值得做；V3 与 V1/V2 信号时间完全不重叠（重合次数 0）
- 双向持仓资金费率净影响为 0（一边付一边收，仓位相等时）

**评判标准（提前锁定，不随市场波动改变）：**
- 评判周期：6 个月
- 干预线：实盘回撤超过历史最大回撤的 1.5 倍才考虑暂停
- 不因某个月 V1/EMA 跑赢而回调权重

## 版本命名规范

见 `crypto/CLAUDE.md`。注意：SOL 的 v3 是 205m（不是 3h），与 ETH 版本命名**不对应**。历史分析中曾称 205m 版本为"V4"，当前脚本统一为 `v3_205m`。

新增标的或策略时，先运行 `crypto/analysis/run_all.py` 计算加入后的组合回撤变化，再决定是否配置。
