## 跨标的组合（2026-05-22，按最大回撤排序）

| 组合 | 净利润 % | 最大回撤 % | 夏普 |
|------|---------|-----------|------|
| **ETH+SOL** | **133.7%** | **4.3%** | **2.72** |
| BTC+SOL | 101.7% | 4.4% | 2.38 |
| BTC+ETH+SOL | 111.9% | 4.5% | 2.69 |
| 全4标的 | 112.5% | 4.9% | 2.60 |

- **最优**：ETH+SOL（回撤 4.3%，夏普 2.72）
- **含BTC最优**：BTC+ETH+SOL（回撤 4.5%，夏普 2.69）
- DOGE 加入后回撤上升，谨慎配置

## 各标的推荐配置

- **ETH**：v2+v3_205m（夏普 2.14，回撤 6.5%）
- **SOL**：v2+v3_205m（夏普 2.64，回撤 6.9%）
- **BTC**：ema+v2+v3_205m（单标弱但分散化价值高，融合回撤 6.2%）

新增标的或策略时，先计算加入后的组合回撤变化。分析入口：`crypto/analysis/run_all.py`。
