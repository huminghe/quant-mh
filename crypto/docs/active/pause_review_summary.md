# 策略暂停/审查机制 — 决策总结

本文件是给别人讲解或自己回顾"策略什么时候该暂停"这件事的**唯一入口**。按"问题→验证→结论→当前规则"顺序自包含写完，不需要翻 `strategy_research_log.md`（过程日志，1200+行）或 memory（跨会话摘要指针）。

## 背景：两套不同的机制，不要混淆

项目里有两套"暂停"相关机制，服务不同问题：

| 机制 | 文档 | 触发信号 | 性质 |
|------|------|----------|------|
| 事件驱动短期暂停 | `pause_mechanism.md` | 3周跌超12% + 布林带异常扩张 + Stoch走弱（且逻辑） | **前瞻性**：在波动率高位时触发，赌接下来会横盘 |
| 月度健康度监控 | `health_monitor.md` | 滚动3个月盈亏比/胜率/Sharpe破线 | **结果性**：发现策略近期表现已经变差 |

本文档只讲**第二套（健康度监控）**的暂停决策问题。第一套历史5次触发4次有效（80%命中率），样本少但逻辑自洽，继续保留，没有争议。

## 问题

健康度监控原规则是："盈亏比/Sharpe连续破线 → 触发审查 → **可能暂停策略**"。

这条规则从没被验证过——"审查后暂停"本身是否能带来正收益，还是单纯的心理安慰？2026年10月BTC_ema/BTC_v2/DOGE_v2接连破线，第一次把这个问题摆到台面上（详见下方时间线）。

## 验证过程（2026-10-21 ~ 11-04）

**第一步，直接回测"暂停有没有用"。** 把历史上所有盈亏比破线事件拉出来，分别算"触发后暂停30天/50天，收益是否比不暂停更好"。

- 原始阈值（1.58）下只有6次独立触发事件，样本太小，看似有正向倾向（30天档4好1差1平）但不敢下结论。
- 放宽阈值到2.00，样本扩大到17次，结果**反转**：30天档变成8好8差1平，50天档6好11差——暂停越久反而更差。
- 判定原来6次的"正向倾向"是小样本噪声，不是真实效果。

**第二步，怀疑是不是指标选得不好，系统性测了5个候选判据。** 盈亏比、胜率、Sharpe、MFE比值（有利波动收窄程度）、CUSUM变点检测——单独用、两两组合、三组合，三层全部回算。

- **三层全部证伪**，没有一个组合支持"触发后暂停"。
- 根因：这5个指标全是**结果性/滞后指标**。退化发生后才触发，触发时退化阶段往往已经过去一部分，这时候暂停30-50天，经常刚好错过随后的修复或反弹。这跟 `pause_mechanism.md` 的价格+波动率+前瞻性触发机制根本不是一回事，不能类比复用。

**第三步，确认不存在例外。** 有没有可能"归因指向系统性市场因子（而非策略本身问题）时，可以破例暂停"？

- 这条路也没有数据支持，已从规则里去掉。
- 2026-11-04首次实跑归因脚本（`attribution_check.py`），对10月破线的4个策略（BTC_v2/BTC_v3_205m/DOGE_v2/SOL_v2）做客观化检查，4/4一致指向"趋势耗尽"（MFE收窄），判定是系统性市场环境问题——但即便判定为系统性，结论依然是不暂停，只记录归因。

**第四步（独立交叉验证），市场本身是否真的变弱了。** 跳出策略PnL，直接用ADX/效率比/年化波动率/ATR%这些价格指标，看市场趋势性/波动性是否系统性减弱，验证归因是否可信。

- 波动率收缩在16组"标的×框架"组合里全部成立，跨周期一致。
- 趋势性只在4h/1h中短周期上4/4标的显著减弱，日线/8h基本没变。
- 逐月拆分后发现实际是**强弱交替震荡**，不是单调走弱——09月趋势性曾单月回升到6个月最高，10月只是中游水平。所以准确的说法是"市场切换更频繁"，不是"持续走弱"。

## 结论

1. **健康度监控触发审查后，不暂停。** 只用 `attribution_check.py` 做归因记录，帮助理解"为什么变差"，不作为暂停依据。
2. 不存在"归因指向系统性因子就可以例外暂停"的路径，这个口子本身没有数据支持。
3. 5个候选判据（盈亏比/胜率/Sharpe/MFE比值/CUSUM）方向已穷尽，不需要再找新指标重复验证同一个问题。
4. 跳出PnL看市场本身：波动率确实在收缩（跨周期一致），趋势性只在中短周期减弱且是震荡式而非单调式——这支持"当前是正常的市场状态切换，不是策略失效"的判断，但本身不构成暂停或继续的直接依据。

## 当前规则（落地到 health_monitor.md）

| 情况 | 动作 |
|------|------|
| 单月盈亏比/胜率低于阈值 | 记录，继续执行，不调整 |
| 连续2个月盈亏比破线，或滚动12月Sharpe连续2-3月<0 | 触发审查，**不暂停**，跑 `attribution_check.py` 做归因记录 |
| 最大回撤超历史最大回撤1.5倍 | 暂停策略，重新评估（这条规则独立于本文档讨论的内容，未被证伪） |

完整触发阈值表、心态管理原则、历史参照数据见 `health_monitor.md`。

## 唯一的例外决策（不是这套规则本身的产物）

2026-10-21，BTC_ema被实际暂停——但这不是"审查后暂停"规则触发的，是基于另外两个独立理由的人工判断：回撤深度是历史第二深回撤的1.9倍（远超统计意义上的异常）、且与BTC_v2相关性0.72持仓高度重合（两个策略同时跑有冗余）。本文档讨论的"暂停是否有用"证伪结论，不覆盖这类极端值+冗余度的人工判断场景。
