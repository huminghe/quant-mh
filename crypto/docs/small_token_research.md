# 小币调研结论汇总（2026-05）

> 调研目的：了解市场动态，均未参与。用于未来新标的筛选时的排除参考。

## 核心结论

这批新上所小币普遍存在：低流通量操盘结构、上所即出货、概念炒作居多。

## 各标的调研结论

### BSB（Block Street）
- 定位：RWA/链上资本市场统一流动性层
- 被 Trump 家族关联公司 AI Financial（NASDAQ: AIFC）以最高 $4300 万收购
- 风险：Trump 概念炒作、流通量仅 20%、收购方存在利益冲突
- 结论：概念炒作，基本面薄弱

### LAB（LABtrade）
- 定位：多链交易执行层 + AI 研究引擎
- ZachXBT 指控：内部人控制 95%+ 供应，低流通操盘，已完成一轮拉盘出货（+500% 后 -84%）
- 结论：链上侦探公开点名的操盘币，风险极高

### BILL（Billions Network）
- 定位：AI 身份验证网络，对标 Worldcoin，Coinbase Ventures + Polychain 投资
- TGE 前单方面将解锁条款从 75% 改为 6-12 个月锁仓，引发社区强烈反弹
- 流通量 24%，团队钱包已向交易所转入代币
- 结论：团队背景较强但改锁仓条款是重大信任危机信号

### EDEN（OpenEden）
- 定位：RWA 协议，代币化美国国债（TBILL + USDY）
- 上线即出货：从 $1 跌至 $0.04 区间（跌幅 95%+），近期有异常拉升（+72%/24h）
- 结论：产品方向真实，但 EDEN 代币已完成一轮完整出货周期

### UB（Unibase）
- 定位：AI Agent 去中心化记忆层（Membase + AIP + Unibase DA）
- 亮点：无 VC 融资、全流通（无锁仓炸弹）
- 风险：产品早期，AI Agent 赛道竞争激烈，团队占 18% 随时可市场出售
- 结论：代币结构相对干净，但项目早期，赛道赢家未定

### SPACE（Spacecoin）
- 定位：卫星驱动的去中心化互联网（DePIN），已有 2 颗卫星在轨
- 与 World Liberty Financial（Trump 关联）合作
- 流通量仅 10.25%，后续 89.75% 持续解锁，从 ATH 跌 87%
- 结论：技术基础最扎实（真实硬件），但代币经济学差，商业化周期极长

### RIVER（River）
- 定位：跨链稳定币系统（satUSD），Arthur Hayes + Justin Sun 投资
- 链上分析：单一实体用 2418 个钱包控制约 50% 流通供应，81% 供应集中在 5 个钱包
- 从 ATH $87 跌至 $7.5（跌幅 91%）
- 结论：链上风险信号最明确，操盘痕迹显著

### RAVE（RaveDAO）
- 定位：去中心化音乐娱乐生态，线下电子音乐节 + Web3
- 有真实线下活动（累计 10 万+ 参与者），Warner Music 合作
- 从 ATH $27.94 跌至 $0.65（跌幅 97.7%）
- 结论：有真实业务但娱乐 IP 代币化赛道历史成功案例极少

### OFC（OneFootball Credits）
- 定位：足球粉丝经济代币，OneFootball 平台（2 亿月活）
- 融资超 $3 亿，Animoca Brands + Dapper Labs 投资
- 流通量 16.1%，从 ATH $0.10 跌至 $0.052（跌幅 48%）
- 结论：基本面最扎实（真实用户、真实融资），但体育粉丝代币赛道整体表现差

## 共性风险特征（用于未来筛选排除）

1. 流通量 < 20%：低流通操盘结构，上所即出货概率高
2. 上所后短期暴涨再暴跌：已完成出货，不适合追入
3. ZachXBT/链上侦探点名：直接排除
4. TGE 前单方面改变条款：团队信任危机信号
5. Trump/名人概念：短期炒作，基本面通常薄弱
6. 期货交易量超现货 80 倍以上：杠杆驱动，非有机需求
