## A股指数增强（多因子选股）

**状态：研究阶段，尚无可接入实盘的完整方案。**

- 核心方向：传统固定权重因子组合（低波动/EP/ROE/反转等）全部未达验收标准，核心瓶颈是A股频繁风格切换下因子权重必然衰减
- 唯一跑通的方向：指数样本股定期调整效应（事件驱动，被动基金资金流），完整验证通过（含成本/涨跌停约束），实盘接入方案已开发完成，但**尚未遇到真实调整事件窗口**（下一次是2026年12月）
- 新因子挖掘：累计测试超过52类候选（跨因子选股、确定性事件两大子类），仅上述指数调整效应1个通过完整验证，其余均证伪或数据不可行
- 当前阶段：四类换源来源（海外机构研报/学术论文/博客社区/国内量化社区+交易所公告）已全部穷尽，暂无新待办方向，等待12月真实调整事件验证实盘接入方案
