## 架构

### 两层结构

```
Layer 1: ETF动量信号
  ↓ 每月月末计算所有ETF的风险调整动量得分 + 拥挤度软过滤
  ↓ 选出得分Top3的ETF

Layer 2: 仓位构建
  ↓ 对每个选中ETF判断类型：
    - 行业ETF → 映射到申万行业 → 从中证500成分股中选Top10个股
    - 宽基ETF → 直接持有ETF本身
```

### 仓位分配

- 总仓位三等分，每个ETF槽位占1/3
- 行业ETF槽位：10只个股等权，每只个股占 1/30 总仓
- 宽基ETF槽位：直接持有该ETF，占 1/3 总仓
- 月度调仓，下月第一个交易日执行

## 实现方案

**新脚本：** `a_stock/backtest/etf_stock_hybrid_backtest.py`

复用模块：
- `etf_rotation_v3b_crowding.py` 的动量得分 + 拥挤度计算逻辑
- `factor_multi_backtest_v2.py` 的因子计算函数（直接import）
- `fetch_index_members.py` 的 `load_members_pit`（PIT成分股）

主流程：
1. 加载ETF收盘价 + 个股收盘价（合并面板）
2. 月末循环：
   a. 计算ETF动量得分 + 拥挤度调整
   b. 选Top3 ETF
   c. 对每个选中ETF：判断类型 → 构建持仓（ETF或10只个股）
   d. 计算月度收益（扣成本）
3. 输出：全样本/IS/OOS统计 + 年度超额分拆 + 与基线对比净值图

## 验收标准

- 全样本超额（vs纯ETF轮动）> 0
- IS超额 > 0
- OOS超额 > -2%（允许略微下降，但不能大幅恶化）
- 年度超额分拆：2019-2021成长牛市期间不大幅跑输（核心诊断点）
