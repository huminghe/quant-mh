# 数据约定

- **A股复权（个股）**：默认使用后复权（`adj_type='hfq'`），因子计算用后复权价格
- **⚠️ A股复权（ETF）**：tushare `pro_bar(asset="FD", adj="hfq")` 对ETF不可信——不处理份额折算（拆分/合并）事件的复权，会产生价格断层（实测最大-90%）。必须用 `adj=None` 拉取不复权价 + `fund_adj` 复权因子手工相乘还原。`fund_adj` 单次调用有约2000条静默截断上限，长区间要分段（≤2年一段）拉取再拼接，否则早期日期漏复权、在截断点产生新断层。已实现于 `a_stock/data/fetch_data.py`。
- **tushare 日线字段**：`trade_date`（日期）、`open/high/low/close/vol/amount`
- **akshare 字段**：注意日期列名可能是"日期"或"date"，使用前统一重命名
- **加密货币**：使用 USDT 计价的永续合约数据，频率与策略信号频率一致
- **⚠️ 时区对齐（加密货币）**：TV 导出交易记录是 UTC+8 naive datetime，Binance/OKX API 是 UTC。合并前必须先转换：`df['entry_dt'] = pd.to_datetime(df['entry_dt']) - pd.Timedelta(hours=8)`。未对齐等效于用了未来 8 小时数据，导致所有正向结论为假。
- **⚠️ 多标的矩阵末尾NaN**：不同标的数据更新日期可能不同步，矩阵末尾会出现大量NaN行。回测前必须截断到超过半数标的有数据的最后一天，否则持仓净值会假性暴跌至仅剩现金。`load_close_matrix` 已内置此截断逻辑。
- **⚠️ 日频/跨市场信号的IC检验要拆到可执行段**：检验"隔夜海外收益预测A股次日收益"一类信号时，若只算close-to-close的IC，会把"昨收→今开"的跳空缺口收益也算进预测力——但A股在缺口发生前无法用旧价提前买入，这部分不可交易。必须拆成`gap_ret=open/prev_close-1`（隔夜缺口，不可交易）和`intraday_ret=close/open-1`（日内段，可交易）分别算IC，只有日内段IC才代表真实可获取的信号强度（实测案例：表观IC=0.177，拆解后可执行部分只有0.069，58%的表观信号强度来自不可交易缺口）。

# 回测验收标准

每次回测结束，输出必须包含以下指标，缺一不可：

**样本内（训练集，前 80% 数据）：**
- 年化收益率
- 年化夏普比率（使用无风险利率 2%）
- 最大回撤
- 胜率、盈亏比

**样本外（测试集，后 20% 数据）：**
- 以上全部指标重复报告
- 样本内外夏普比率之比（若样本外 < 样本内 × 0.5，需标注"可能过拟合"）

**多重测试警告：**
- 若测试了多个参数组合，必须注明测试组合数量（n_trials）
- 若 n_trials > 10，建议用 Deflated Sharpe Ratio 或 Bonferroni 校正评估显著性
- 禁止只报"最优参数"的结果而不说明测试了多少组合
- **n_trials 怎么数**：按"在同一份（有重叠的）历史数据上比较过的候选总数"计，不按时间先后、也不按"这次尝试最后是否被采纳"筛选。跨多轮调研持续对同一段历史数据做优化，属于同一次多重检验过程，每一轮/每一组网格产生的候选都要累计计入，不能因为"后面大部分尝试都失败了/是很久以后才做的"而只按最早选出参数时的试验数计算——DSR校正的是"N次尝试里挑出最大值"这件事本身的运气膨胀，跟冠军诞生的时间顺序无关。
- **PBO/CPCV 候选集合要求**：计算 PBO 前必须确认候选集合同属一次参数搜索、回答同一个调参决策（如同一网格的不同格点）。跨方向/跨脚本汇总的历史结果不能直接合并成一个矩阵——"样本内最优"在混合决策下会在不同路径里指向完全不同性质的候选，复合结果无清晰含义。候选数 <7 时 CPCV 统计意义也不足，不要硬跑。

**滚动窗口稳健性检验：**
- 若使用滚动窗口验证（如滚动2-3年夏普），需报告滚动窗口数量、均值、标准差
- 劣于基线占比 >30% 视为不稳健（历史判例：32.3%判过拟合，18.8-18.9%判稳健，20-25%为灰色地带需结合其他证据）

# A股特殊处理

- **T+1**：当日买入不可当日卖出，回测信号需延迟一天执行
- **涨跌停**：涨停无法买入、跌停无法卖出，需在回测中模拟无法成交的情况
- **退市/ST**：因子选股时需过滤 ST 股和上市不足 6 个月的新股
